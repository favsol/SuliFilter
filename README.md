Thanks for trying SuliFilter!

SuliFilter is a Windows Management software made for parents to make limit kids devices easily and stay safe using Windows.

To use SuliFilter, open the SuliFilter folder wherever you installed it, and find SuliFilter.exe
It may ask for UAC Access (User Account Control), don't worry, this allows you to set restrictions on the computer.
Browse through the Dashboard application. You may see "Browser Restrictions" this can be setup easily.

HOW TO ENABLE BROWSER RESTRICTIONS

Using Google Chrome to setup Browser restrictions, use the address bar and go to chrome://extensions
Toggle ON Developer Mode (usually at the top right) and find and click the button that says, "Load unpacked"
Find the SuliFilter folder and find "BrowserExtension" press Select Folder and import it into Chrome. Toggle the extension on, and now you can set Browser restrictions using the SuliFilter Dashboard app.

Other information
SuliFilter is still in BETA and some listed features may not work correctly, we're still working on fixing features that may not work correctly


SULIFILTER IS REQUIRED TO HAVE .NET RUNTIME!
Download .NET Runtime using the official download link: https://dotnet.microsoft.com/en-us/download/dotnet/8.0
Find the Windows download and install it.
